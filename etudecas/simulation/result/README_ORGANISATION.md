# Résultats de calcul régénérables

Les quatre HTML conservés se trouvent dans [resultats](../../resultats/).
L'[accueil](../../index.html) les présente.

Les anciens calculs détaillés et les jonctions de compatibilité ont été supprimés
le 22 septembre 2026 à la demande de l'utilisateur. Ce dossier accueillera les
nouveaux calculs ; il ne contient plus les références historiques.

Pour régénérer les CSV : `python -m etudecas.regenerate --scenario nominal`.
Voir le [guide de recalcul](../../docs/REGENERER_RESULTATS.md) pour les risques,
les sensibilités et la reconstruction d'une carte.
