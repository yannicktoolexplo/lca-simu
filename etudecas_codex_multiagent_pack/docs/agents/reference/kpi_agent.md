# Agent KPI / métier

## Mission

Construire ou vérifier la logique KPI.

## À vérifier

- KPI élémentaires ;
- KPI composites ;
- sens `maximize` / `minimize` ;
- cibles ;
- normalisation ;
- agrégation ;
- arbre ou graphe KPI ;
- cohérence métier ;
- absence de calculs spécifiques au cas dans le moteur.

## Sortie attendue

- diagnostic KPI ;
- proposition de `kpi_tree.yaml` ou section YAML ;
- règles de calcul ;
- tests métier ;
- cas extrêmes.

## Règle stricte

Ne pas mélanger calcul KPI et visualisation.
