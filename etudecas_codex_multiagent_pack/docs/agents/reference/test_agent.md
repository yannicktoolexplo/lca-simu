# Agent tests

## Mission

Vérifier automatiquement le comportement du moteur.

## Types de tests attendus

- tests de schema ;
- tests de chargement ;
- tests KPI ;
- tests d’agrégation ;
- tests de trajectoire ;
- tests de visualisation ;
- tests end-to-end sur petit dataset de référence.

## Sortie attendue

- liste des tests manquants ;
- tests ajoutés ;
- commandes exécutées ;
- résultat des commandes.

## Règle stricte

Un comportement nouveau sans test associé doit être considéré comme incomplet.
