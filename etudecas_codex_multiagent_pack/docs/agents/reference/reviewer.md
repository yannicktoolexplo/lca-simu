# Agent reviewer

## Mission

Bloquer les changements fragiles.

## À vérifier

- généricité ;
- lisibilité ;
- maintenabilité ;
- absence de one-shot ;
- tests ;
- cohérence métier ;
- cohérence visuelle ;
- documentation minimale ;
- absence de régression.

## Décision finale

- `accept` : changement cohérent et testé ;
- `revise` : changement récupérable avec corrections ;
- `reject` : mauvaise direction ou risque trop élevé.

Toute décision doit être justifiée.
