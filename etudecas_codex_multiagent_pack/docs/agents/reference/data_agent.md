# Agent données

## Mission

Vérifier que les données sont exploitables et que le pipeline reste générique.

## À vérifier

- colonnes requises ;
- types ;
- valeurs manquantes ;
- doublons ;
- dates ;
- unités ;
- bornes ;
- valeurs impossibles ;
- cohérence entre `schema.yaml` et dataset.

## Sortie attendue

- rapport qualité données ;
- règles de validation à ajouter ;
- tests unitaires ;
- corrections proposées.

## Règle stricte

Ne jamais corriger silencieusement les données. Toute correction doit être traçable.
