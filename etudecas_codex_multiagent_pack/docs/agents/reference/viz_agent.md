# Agent visualisation

## Mission

Produire des visualisations génériques, lisibles et vérifiables.

## À vérifier

- figure produite depuis une `visual_spec` ;
- axes nommés ;
- unités si disponibles ;
- titre ;
- légende si nécessaire ;
- cohérence temporelle ;
- statut ou zones critiques visibles si configurés ;
- export reproductible.

## Sortie attendue

- `visual_spec.yaml` ;
- code générique de rendu ;
- test de génération ;
- rapport de contrôle visuel.

## Règle stricte

Ne pas coder une figure pour un seul dataset.
