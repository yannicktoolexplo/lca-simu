# À qui consacrer cinq places en revue fournisseur ?

## Acquis du cahier

Sur 27 fournisseurs simulés, quatre places mono-source et une autre donnent 9,09 % de listes sans baisse détectée.

Le second classeur confronte le service client au respect du programme de production sur 203 perturbations. Le service est stable dans les 203 cas. Le respect du programme baisse dans 33 cas. Il permet de sélectionner les écarts à examiner avant la revue.

Capacité et délai confirmés par référence, y compris sur les fournisseurs laissés hors revue. Calcul possible sur le portefeuille d’origine.
